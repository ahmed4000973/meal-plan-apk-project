How to get the APK (no Android Studio needed):
1. Create a free GitHub account and a new empty repository.
2. Upload ALL files in this folder to it (keep the .github folder).
3. Open the repository > Actions tab > "Build APK" > wait ~5 minutes.
4. Open the finished run, download "meal-plan-apk", unzip it, and send app-debug.apk to your phone.
5. On the phone, allow "Install unknown apps" for your file manager/browser and open the APK.
Your progress is saved on the phone. The "إعادة ضبط كل البيانات" button at the bottom of each screen clears it.
